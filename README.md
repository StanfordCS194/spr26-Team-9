## Repository Overview

### `frontend/`
Frontend for the user-facing web application. 

### `webscraper/`
This directory will contain the automated data ingestion and NLP analysis pipelines.

### `experiments/`
Python scripts for exploratory analysis and visualization. Run scripts from the repo root (e.g., `python experiments/visualize_nyt.py`).

### `visualizations/`
Output figures generated by scripts in `experiments/`.
